## Features

**Live network speed in the menu bar**
- See download and upload speed every second, e.g. `24.6 MB/s↓`
- **Auto mode** shows only the busier direction, so it takes very little space
- **MB/s** (like file sizes) or **Mbps** (like speed tests)
- Fixed width, so your menu bar never jumps
- Looks native in Light Mode, Dark Mode and on any wallpaper

**Liquid Glass panel.** Hover over the speed or click it to see:
- Big, clear download and upload readings
- A 60-second traffic graph
- Data received and sent, plus the peak speed
- Your Wi-Fi or Ethernet status

**CPU & memory**
- Live CPU % with a graph
- Memory used, with a colour-coded memory pressure bar
- Swap usage and core count

**Keep Awake ☕.** Never lose a download to sleep:
- **30 minutes to 8 hours** (2 hours by default), or **Until I turn it off** (still capped at 8 hours)
- **While downloading:** stays awake only while data is moving, then lets the Mac sleep after 5 quiet minutes
- Optional: keep the screen on too
- Stops by itself when the battery drops below 20%
- Optional "Download finished" notification

**Private and lightweight**
- No account, no ads, no tracking
- Meterly makes no internet connections of its own
- Uses almost no CPU or battery

## FAQ

**MB/s or Mbps?**
Speed-test sites show megabits (Mbps). File sizes use megabytes (MB). 1 byte = 8 bits, so **15 MB/s = 120 Mbps**. At 15 MB/s, a 15 MB file downloads in about one second.

**I can't see Meterly in the menu bar.**
Open **System Settings → Menu Bar** and make sure Meterly is turned on. On MacBooks with a notch, a full menu bar can hide items, so try quitting a few other menu bar apps. You can also hold **⌘** and drag Meterly to a new spot.

**Does Keep Awake work with the lid closed?**
No. When you close the lid on battery, macOS always sleeps, by design. Keep Awake prevents *idle* sleep while the lid is open.

**Does Meterly collect any data?**
No. See the [Privacy Policy](PRIVACY.md).

**How do I quit or uninstall?**
Open the panel, click ⚙ and then **Quit**. To uninstall, drag Meterly from Applications to the Trash.
